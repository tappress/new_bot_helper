# Голосовий помічник (Лабораторна робота 4)

## Опис
В цій лабораторній роботі реалізовано функціональність голосового помічника для вже існуючого телеграм-бота. Бот тепер може розпізнавати голосові повідомлення від користувача та відповідати голосовими повідомленнями.

## Функціональність

### 1. Розпізнавання мовлення (Speech-to-Text, STT)
- Реалізовано за допомогою бібліотеки **Vosk**
- Підтримується розпізнавання українських голосових повідомлень
- Можливість розпізнавання з аудіофайлів різних форматів

### 2. Синтез мовлення (Text-to-Speech, TTS)
- Реалізовано за допомогою бібліотеки **gTTS** (Google Text-to-Speech)
- Підтримка багатьох мов, включно з українською
- Відправка голосових відповідей на запити користувача

### 3. Інтеграція з чат-ботом
- Користувач може надсилати голосові повідомлення з питаннями про погоду, курс валют або новини
- Бот розпізнає запит та відповідає як текстовим, так і голосовим повідомленням
- Підтримка природної мови в розпізнаних голосових запитах

## Встановлення та налаштування

### Встановлення залежностей

```bash
pip install -r requirements.txt
```

### Встановлення додаткових компонентів

1. **FFmpeg** (необхідний для обробки аудіофайлів)
   - Для Ubuntu/Debian:
   ```bash
   sudo apt-get install ffmpeg
   ```
   - Для Windows: завантажте з [офіційного сайту](https://ffmpeg.org/download.html)

2. **Vosk моделі**
   - Завантажте українську модель з [сайту Vosk](https://alphacephei.com/vosk/models)
   - Рекомендовані моделі:
     - `vosk-model-uk-v3` (повна модель)
     - `vosk-model-small-uk-v3` (легка модель)
   - Розпакуйте модель в кореневу директорію проекту

### Налаштування середовища

Створіть файл `.env` з наступними змінними:
```
NEWS_API_KEY=ваш_ключ_новинного_api
WEATHER_API_KEY=ваш_ключ_погодного_api
TELEGRAM_BOT_TOKEN=ваш_токен_телеграм_бота
API_BASE_URL=http://localhost:8000
```

## Запуск бота

### 1. Запуск API сервера

```bash
cd /path/to/project
python -m api.app
```

### 2. Запуск телеграм-бота

Перейдіть в директорію проекту і запустіть скрипт:

```bash
cd /path/to/project
python -m bot.main_modified
```

## Використання бота

### Команди бота

- `/start` - Початок роботи з ботом
- `/help_voice` - Інформація про голосові можливості бота
- `/voice` - Тестування голосових можливостей бота
- `/weather` - Запит погоди
- `/currency` - Запит курсу валют
- `/news` - Запит новин

### Приклади голосових запитів

Користувач може надсилати голосові повідомлення з наступними запитами:

- **Погода**: "Яка погода у Києві сьогодні?", "Погода у Львові", "Температура в Одесі"
- **Валюта**: "Який курс долара?", "Курс євро до гривні", "Вартість євро"
- **Новини**: "Останні новини", "Новини спорту", "Що нового в світі?"

### Голосові відповіді

Бот відповідає на голосові запити як текстом, так і голосовим повідомленням. Текстова відповідь містить детальнішу інформацію, тоді як голосова - скорочену версію.

## Технічні деталі

### Розпізнавання мовлення (STT)

Для розпізнавання мовлення використовується бібліотека Vosk. Процес розпізнавання:

1. Отримання голосового повідомлення
2. Перетворення аудіо в потрібний формат (WAV, 16kHz, mono)
3. Обробка аудіо через Vosk модель
4. Отримання розпізнаного тексту

### Синтез мовлення (TTS)

Для синтезу мовлення використовується Google Text-to-Speech (gTTS):

1. Підготовка тексту для синтезу
2. Створення аудіофайлу через gTTS
3. Відправка синтезованого аудіо як голосове повідомлення

### Інтеграція з NLP

Розпізнаний текст обробляється через модуль обробки природної мови (NLP), який:

1. Визначає намір користувача (погода, валюта, новини)
2. Витягує необхідні сутності (місто, валюта тощо)
3. Формує відповідь на основі наміру та сутностей

## Можливі покращення

1. **Офлайн моделі для TTS**: Заміна gTTS на офлайн-рішення (наприклад, Piper або eSpeak)
2. **Покращення NLP**: Розширення можливостей розпізнавання намірів
3. **Оптимізація голосових відповідей**: Створення більш природних голосових відповідей
4. **Автоматична мовна локалізація**: Визначення мови запиту та відповідь тією ж мовою
5. **WebSockets**: Реалізація потокового розпізнавання для довших аудіозаписів
